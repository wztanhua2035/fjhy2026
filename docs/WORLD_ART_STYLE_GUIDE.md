# 《富甲横阳》小镇整体风貌与人物服饰统一规则 V1

**状态：【已确定｜重要世界观与美术总则】**

本规则是《富甲横阳》建筑、场景、NPC 服饰、主角服装及未来新区域设计的上位规则。后续新增街区、建筑、NPC、主角服装、场景设施时均应优先遵循；当前已验收的白石街素材不因此要求返工，新规则从后续新增素材与自然迭代开始执行。

## 1. 世界风貌总定位

《富甲横阳》不是古代背景，也不是纯架空古风。正式定位为：

> **以当代东南沿海小镇为现实基底，保留传统街巷、地方建筑、手艺铺、老字号和人情生活，同时自然融入现代建筑、现代商业、现代服饰和现代生活设施，形成“传统与现代共存”的轻幻想日式 RPG 小镇。**

核心关键词：**当代小镇 / 东南沿海 / 传统底色 / 现代生活 / 日常烟火 / 轻幻想 / 风格化表达**。不追求严格历史复原；不要求所有建筑均为古建筑、所有居民均穿传统服饰；不排斥现代商业与公共设施；允许审美理想化和游戏化，但始终应让玩家感到这是同一座横阳小镇。

## 2. 传统与现代：有秩序地混合

原则不是古今乱搭，而是：**传统决定小镇的文化底色，现代体现小镇正在生活和发展。**

老街可有老木屋、瓦顶店铺、百年商号、传统茶馆和手艺铺，也可合理出现玻璃门窗、现代灯箱、空调外机、电线、电表箱、电动车、快递点、理发店、奶茶店、便利店、手机维修店和现代广告牌。它们必须采用统一的 RPG 风格化表达，不能把现实照片式设施生硬贴入传统街景。

传统建筑允许有玻璃门、新式招牌、电灯、空调、电线、摄像头、现代家具、收银设备、冰箱、现代货架和座椅等现实生活痕迹；“旧房子里过现代生活”是横阳镇的重要特色。

## 3. 建筑风貌的三层区域结构

### A. 老街核心风貌区（传统强）

以白石街为代表，适合老字号、客栈、商行、杂货铺、茶馆、琴馆、衣坊、手艺铺、小吃铺、历史建筑、宗祠和寺观。其主要语言为瓦屋顶、木构、白墙、老招牌、檐廊、石板路，以及丰富植物和生活杂物。老街不是古装影视城，而是延续到今天、仍有人生活的老街；可适量融入现代设施。

### B. 生活混合区（传统现代混合）

未来扩展的主要区域，适合普通住宅、早餐店、药店、小超市、五金店、理发店、快递点、菜市场、餐馆、小旅馆、咖啡馆、奶茶店、文具店、宠物店和社区服务设施。建筑可呈现约 **传统 40%～60% + 现代 40%～60%**：允许瓷砖外墙、水泥建筑、卷帘门、玻璃门、雨棚、阳台、空调与现代门头，但应保持温暖、清新、小尺度的小镇感。

### C. 新城 / 功能区（现代较强）

可承载政府大楼、银行、学校、医院、商场、写字楼、酒吧、KTV、酒店、娱乐场所、城市广场、公交站、停车场和连锁商业。此类建筑可更现代，但必须与其他区域统一人物比例、建筑尺度、色彩、线条语言、光影和游戏化程度，不能突然变成完全不同画风的都市游戏。

## 4. 人物服饰：多时代混合

横阳镇居民不统一穿古装。NPC 服饰长期允许并存四类：

### A. 传统生活型

适合年长居民、老掌柜、老手艺人、茶人、琴师、老街居民与传统行业角色；可采用对襟衫、布衣、长衫、布裤、围裙、布鞋和传统发饰。

### B. 改良传统型

适合重点 NPC 与有个性的角色，如店主、主理人、文艺青年、女掌柜、美发师、衣坊人物及主角部分服装。可采用中式上衣配现代裤装、改良旗袍元素、中式裙装、传统纹样配现代剪裁、古典发饰配现代发型、围裙和布包等生活化元素。

### C. 现代日常型

必须成为小镇常见类型。年轻居民、游客、学生、普通店员、街头路人和上班族可穿 T 恤、POLO、衬衫、牛仔裤、休闲裤、半裙、连衣裙、卫衣、夹克、运动鞋与帆布鞋。不得因白石街传统感较强，就让后续所有 NPC 都穿古风服装。

### D. 现代职业型

医生、护士、教师、公务人员、保安、厨师、服务员、美发师、酒吧/KTV 员工、快递员、店员与公司职员等，应具有自然的职业识别度；服装仍需经过游戏风格化。

NPC 服饰应承担人物塑造：依据**年龄、性格、职业、所在街区、收入层次、兴趣与生活方式**决定穿着，避免“100 个 NPC 换脸却穿同一套古装”。

## 5. 店铺、现代设施与统一美术语言

横阳不是仅有古风店铺的古镇游戏。酒吧、KTV、咖啡馆、奶茶店、网吧、游戏厅、商场、超市、写字楼、政府办公楼、学校、医院、现代酒店、银行、电影院、体育馆、健身房、快递站、手机店等现代场所均允许存在；前提是位置合理、建筑语言统一、颜色协调、世界观解释自然。

年代可以混合，画面语言必须统一：Q 版人物比例、建筑比例、透视角度、描边程度、材质表现、植物风格、光影方向、色彩饱和度、UI 气质和像素 / 手绘转换标准应保持一致。

整体长期保持**清新、温暖、明亮、有生活感**。避免极端高饱和霓虹、大面积冰冷金属、纯赛博朋克、极暗末世风、过度写实灰脏，以及与 RPG 画风完全不同的照片式建筑。即使制作酒吧或 KTV，也应使用小镇式、柔和、游戏化的夜间灯光，而非赛博都市。

现代元素可包括汽车、电动车、自行车、公交站、快递车、手机、电脑、家电、现代广告、自动售货机和公共设施，但必须服务于生活感，不能抢走地方性、街坊感、人情味和历史痕迹。

## 6. 主角模块化外观与 NPC 状态

既定的主角模块化外观系统必须同时兼容传统、改良传统与现代服装。主角未来可拥有短褂、中式衬衫、改良裙装、传统纹样外套，也可拥有 T 恤、牛仔裤、衬衫、卫衣、半裙、连衣裙与外套。

继续采用 `基础身体 + 发型 + 服装 + 饰品`，而非“发型 × 衣服 × 饰品”逐组合制作完整角色。当前男女主角 spritesheet 与 portrait 仍是 Default Appearance + fallback；后续素材须遵守统一身体模板、锚点与 portrait 模板，且不允许只制作传统服装。

核心 NPC 在营业、休息、外出、夜间或特殊剧情等状态中仍保持唯一身份。未来可逐步允许工作服、日常服、节庆服和特殊剧情服装，但第一阶段无需立即实现 NPC 多套换装，也不得在数据设计上将 NPC 永久限制为一套服装。

## 7. 新区域与新素材的前置检查

开发新区域前，必须先定义区域风貌等级：A 传统强、B 传统现代混合、或 C 现代较强。即使 C 类区域也不得脱离《富甲横阳》的统一画风。

区域之间必须渐变：白石街 → 普通生活街 → 商业街 → 新城区，应通过建筑材料、道路、招牌、路灯、NPC 服饰、车辆和店铺类型逐步变化；禁止“走过一个路口，从宋代古街突然变成上海陆家嘴”。

正式美术流程增加：

`世界观定位 → 区域风貌等级 → 建筑 / NPC 时代属性 → 美术制作 → 工程规格 → Web 视觉验收`

制作建筑前确认其区域、传统/现代属性、出现理由与周边衔接；制作 NPC 前确认年龄、职业、生活方式与服饰类别。建筑是否开放室内、室内规模及店铺互动节奏，还须遵循 [《富甲横阳》建筑内部空间三级规则 V1](BUILDING_INTERIOR_SPACE_TIER_RULE.md)。既有工程规格、透明检查、资源模板与跨端验收流程继续有效，详见 [白石街正式美术资源模板 V1](BAISHI_FORMAL_ART_ASSET_TEMPLATE.md)。

## 8. 明确禁止与最终判断

原则上禁止：

1. 将整个横阳镇做成纯古代古镇，或让所有 NPC 都穿古装。
2. 因加入现代建筑而放弃传统底色，或让现代区域成为完全不同画风的都市游戏。
3. 在同一街区无逻辑混入不同画风；以照片写实风制作现代建筑；大量赛博朋克或未来都市元素破坏小镇气质。
4. 为统一而让所有建筑过于相似，或为丰富而无视区域与时代关系。

每个新场景或人物需回答：

1. 它像不像当代东南沿海小镇里可能存在的东西？
2. 它是否保留《富甲横阳》的温度、地方感和 RPG 风格？
3. 它能否与传统、现代两类内容自然共存？

三项大体成立后，才进入正式制作。

> **《富甲横阳》是一座立足当代东南沿海生活的风格化小镇。这里既有瓦檐老街、手艺铺和旧商号，也有咖啡馆、便利店、酒吧、KTV 和现代公共建筑；居民既可以穿布衣长衫，也可以穿 T 恤、牛仔裤和现代职业装。传统不是被冻结的过去，现代也不是对旧城的替代，两者共同构成横阳正在发生的生活。**
