# 白石街样图接入计划

状态：已接入浏览器与微信端测试渲染；已通过配置、入口与碰撞自动测试，待真机视觉验收。

唯一构图基准：apps/admin/public/art-preview/baishi_street_layout_sample_v01.png。

必须以同一份布局配置驱动建筑显示、碰撞、入口和返回位置。禁止只替换整排建筑图片而继续使用旧地块坐标。

以角色脚底为坐标锚点，角色高度接近门洞净高；手机横屏采用等比缩放，样图画幅不等于相机视口。主街、人行道、通往店门的路径必须连续可达。

入口默认 south，允许 west/east，north 仅特殊场景使用。入口已独立配置 position、direction、interactionArea、targetScene、targetSpawnPoint；当前开放建筑各使用一个入口，配置结构允许以后为同一建筑增加多个门。下方入口约占 70%～80%，左右入口合计约占 20%～30%，不强行按少量样本凑比例。

验收要求：每个开放入口可从出生点步行到达；封闭建筑不可穿越；进出返回对应入口；人物、建筑、前景正确排序；浏览器实际截图检查手机横屏比例。自动测试通过不能代替视觉验收。当前浏览器渲染已按挂载表读取图层；候选建筑和前景遮挡层必须完成透明边缘检查后，才允许将 enabled 改为 true。


资源接入约定：

- `packages/game-config/baishi-layers.ts` 是白石街资源路径和渲染顺序的唯一配置入口。
- 浏览器测试页按 `enabled` 和 `z` 加载图层；候选层未经视觉验收不得启用。
- 微信端资源使用相同的 asset key 和文件名，避免浏览器端与小游戏端出现不同构图。
- 建筑候选层当前拆分为 `north` / `south` 两张，后续可继续细分到单栋建筑。
