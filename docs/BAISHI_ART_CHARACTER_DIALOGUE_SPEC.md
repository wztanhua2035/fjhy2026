# 《富甲横阳·白石街角色、美术与对话表现规范 V1》

## 1. 定位与适用范围

白石街统一采用日系清新 Q 版、温暖小镇风格。本规范用于约束白石街及后续复用内容的正式场景、角色与对话表现；它不改变现有服务端、存档、经济或任务规则。

## 2. 美术与角色统一规则

- 建筑、人物与前景使用统一视角、比例、描边、阴影、透明边缘和脚底锚点规范。
- 人物世界坐标代表脚底中心；建筑、前景和人物应按锚点及 depth 规则正确遮挡。
- 美术资源在正式接入前先完成确认；Work 负责 anchor、scale、depth、碰撞、入口、遮挡与 Web/微信跨端测试。
- Web 与微信小游戏端共用同一套正式场景、美术、角色和对话 UI 资源。微信简化画面仅用于早期验证，不形成长期视觉分支。

## 3. 首个正式样板

先以“白石商行 + 白石商行伙计”制作正式样板，在游戏内验证建筑、角色、入口、遮挡和对话表现后，再扩展至其他建筑和 NPC。

“第一桶金”任务中的白石商行伙计是第一套正式剧情对话样板。

## 4. 主角与 NPC 造型

- 主角创建时纳入发型概念；男女各预留 4～6 种基础发型方向。
- 主角以后可在青丝美发室修改发型与发色。
- 玩家识别不能只依赖发型，应由姓名、基础角色身份和当前外观共同构成。
- NPC 原则上保持固定且具有辨识度的发型与服装，不频繁改变造型。
- 主角正式对话半身像后续应尽量同步当前发型、发色与服装。

## 5. 对话三级体系

1. 环境对白：角色头顶小气泡，用于短句、环境提示和路人氛围。
2. 普通对话：底部轻量对话框，可带头像。
3. 重要任务/剧情：保留当前场景作为背景并适度压暗，左右展示 NPC 与主角半身立绘，底部显示正式对白。

当前不为全部 NPC 批量制作半身立绘和表情；优先重要 NPC 与关键任务节点。

## 6. 范围控制

本规范不要求立即扩展完整换装、完整好感、全 NPC 表情或复杂对话演出系统。未确认的素材、裁切和挂载坐标不得由程序侧猜测或自动启用。
