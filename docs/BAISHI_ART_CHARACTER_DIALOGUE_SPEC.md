本规范用于统一《富甲横阳》白石街阶段的角色、美术、建筑、前景遮挡与对话表现标准。
当前目标不是一次性完成全部正式美术，而是先建立一套稳定、可复用、方便后续批量扩展的统一规范，避免后续出现建筑错位、人物比例混乱、NPC辨识度不足、Web 与微信端视觉不一致、对话表现风格反复变化等问题。
当前白石街仍属于纵向切片阶段。执行原则是：
先做样板 → 游戏内验证 → 校准 → 再批量扩展。
白石街正式美术统一采用：
-  2D 俯视 / 轻斜俯视 RPG 视角 
-  日系清新动漫风 
-  Q版但不过度幼态 
-  温暖、轻松、生活化 
-  有小镇商业街的人情味 
-  兼顾 RPG 探索与轻经营模拟气质 
-  画面干净，不做过度复杂的高细节堆砌 
整体应避免：
-  过度写实 
-  强像素复古风 
-  不同建筑各自完全不同的画风 
-  过强二次元夸张效果 
-  过高饱和度 
-  大量杂乱装饰影响可玩区域辨识 
最终目标：
Web / PC 与微信小游戏端在场景、美术、人物、建筑、NPC 和对话 UI 上保持基本一致。
微信端不得长期维护一套独立的“简化视觉版”。
当前白石街采用 48×48 网格体系。
建筑、道路、人物、树木等素材制作与接入时，应考虑：
-  建筑底部落地点 
-  建筑门洞位置 
-  玩家脚底位置 
-  NPC脚底位置 
-  树干落地点 
-  前景遮挡区域 
-  碰撞区 
-  建筑入口触发区 
美术素材不能只考虑“单独看起来好不好看”，还必须考虑“能否稳定接入当前游戏地图”。
当前白石街已有五栋可进入建筑：
-  横阳客栈 
-  街坊杂货铺 
-  白石商行 
-  青丝美发室 
-  春衫衣坊 
五栋建筑可以有明显行业差异，但必须属于同一条街、同一个世界。
统一要求包括：
-  透视方式一致 
-  描边语言一致 
-  明暗关系一致 
-  阴影方式一致 
-  色彩饱和度接近 
-  门窗与人物比例合理 
-  建筑底边落地自然 
-  PNG透明边缘干净 
-  不出现明显白边、脏边、抠图残留 
允许差异包括：
-  招牌 
-  主色 
-  店铺装饰 
-  行业特征 
-  建筑体量 
商行、客栈可以略大；杂货铺、美发室、衣坊可相对轻巧，但整体比例必须协调。
正式建筑优先采用以下结构。
建议文件：
building_xxx_base.png
主体包括：
-  墙体 
-  门窗 
-  主体招牌 
-  固定装饰 
-  不需要遮挡人物的建筑部分 
建议文件：
building_xxx_fg.png
用于：
-  屋檐下沿 
-  门廊顶棚 
-  棚架 
-  人物经过时应位于人物前方的结构 
只拆真正需要前景遮挡的部分，不为了“层次丰富”而无限拆图层。
必要时使用：
building_xxx_ground.png
用于解决：
-  门前台阶 
-  地面拼接 
-  建筑底部与道路衔接不自然 
如果主地图已经能够自然衔接，则不额外制作。
每栋正式建筑必须具备明确的接入参考。
至少需要确认：
-  建筑底边参考线 
-  建筑主体锚点 
-  门洞中心 
-  门洞宽度 
-  推荐显示比例 
-  是否存在前景层 
-  前景层与主体的相对位置 
Work 接入建筑时，不应只通过肉眼反复试坐标。
建筑入口的视觉位置和程序入口触发区必须尽量一致。
避免出现：
-  看起来像门但不能进 
-  玩家进入点偏离门口 
-  人物站在门前像悬空 
-  玩家进入建筑时穿过墙体 
大型树木如果会遮挡玩家，建议分成：
-  树干 / 基础层 
-  树冠 / 前景层 
建议：
tree_xxx_base.png
tree_xxx_fg.png
所有前景 PNG 必须：
-  透明背景 
-  边缘干净 
-  无白边 
-  无残留底色 
-  不影响碰撞逻辑 
树冠、屋檐等前景只负责视觉遮挡，不应承担碰撞逻辑。
主角和NPC统一采用日系Q版角色体系。
人物特点：
-  Q版但不是幼儿化大头娃娃 
-  轮廓清晰 
-  脚底位置明确 
-  动作简洁自然 
-  与白石街建筑尺度协调 
-  手机横屏下仍能辨识人物 
统一要求：
-  头身比 
-  描边粗细 
-  阴影方式 
-  面部简化程度 
-  角色显示高度 
-  脚底锚点 
-  行走方向规范 
NPC之间的差异主要通过：
-  发型 
-  发色 
-  服装 
-  配色 
-  年龄感 
-  职业特征 
-  体态小幅差异 
不通过大幅改变人物基础比例来制造差异。
角色创建阶段增加“发型”作为正式外观维度。
建议初期：
-  男角色 4～6款基础发型 
-  女角色 4～6款基础发型 
优先保证：
轮廓差异明显 > 数量多。
例如男角色可包含：
-  短碎发 
-  偏分 
-  微卷短发 
-  清爽短发 
-  稍长刘海 
女角色可包含：
-  短发 
-  齐肩发 
-  长直发 
-  马尾 
-  丸子 / 半扎 
-  微卷发 
具体款式可以在正式人物样板确认后再定。
“青丝美发室”未来承担真实角色外观功能，而不是纯装饰建筑。
玩家可在美发室：
-  更换发型 
-  更改发色 
后续可扩展：
-  特殊造型 
-  节庆发型 
-  高级发色 
-  特殊服务 
当前阶段只需保留结构，不必立即把完整美发经济系统全部实现。
允许玩家改变发型和发色，但角色识别不能只依赖发型。
玩家识别由多个元素共同构成：
-  玩家名字 
-  基础人物身份 
-  基础脸型 / 体型 
-  当前发型 
-  当前发色 
-  当前服装 
-  当前头像 / 半身像 
因此以后玩家换发型，不应造成严重身份混乱。
普通固定 NPC 不采用频繁换发型机制。
重要NPC应形成明确的视觉记忆点，例如：
-  固定发型 
-  固定职业服装 
-  固定主配色 
-  特征装饰 
例如：
-  陈掌柜 
-  白石商行伙计 
-  街坊杂货铺店员 
应做到玩家看到人物轮廓就能逐渐形成记忆。
主角未来可能发生：
-  发型变化 
-  发色变化 
-  上衣变化 
-  下装变化 
因此主角的正式对话半身像不宜长期使用与实际外观无关的固定画像。
长期方向：
主角半身形象应尽量与当前实际外观同步。
可采用：
-  基础身体 / 脸 
-  当前发型 
-  当前发色 
-  当前服装 
组合生成或同步绘制。
当前阶段不要求立即实现复杂动态换装立绘系统，但架构上避免把主角半身像写死成唯一固定图片。
重要NPC可以制作正式半身立绘。
第一阶段不为全部 100+ NPC 批量制作大量立绘。
优先级：
1.  主线NPC 
2.  当前任务关键NPC 
3.  白石街核心店铺NPC 
4.  重要支线人物 
5.  普通路人暂缓 
普通路人可以长期只使用：
-  场景人物 
-  小头像 
-  简单对白 
当前不为每个NPC制作大量表情。
重要人物第一阶段建议：
-  1张标准半身立绘 
-  必要时增加 1～3种关键表情 
例如：
-  正常 
-  开心 
-  生气 / 惊讶 
不在白石街纵向切片阶段制作几十种复杂表情体系。
正式对话体系分成三个层级。
使用场景：
-  NPC路过自言自语 
-  简单招呼 
-  环境信息 
-  路人闲话 
表现：
NPC头顶小气泡。
特点：
-  不打断玩家移动或只短暂提示 
-  信息短 
-  成本最低 
例如：
“今天白石街可真热闹。”
使用场景：
-  一般NPC交谈 
-  普通商店询问 
-  提示信息 
-  简短交互 
表现：
-  保留当前游戏场景 
-  底部出现轻量对话框 
-  可带NPC小头像 
-  不需要左右大型半身立绘 
重点：
快速、轻量、不打断游戏节奏。
使用场景：
-  主线剧情 
-  支线任务接取 
-  任务关键节点 
-  重要关系事件 
-  重要人物首次登场 
-  剧情选择 
表现方式：
-  当前场景继续作为背景 
-  背景适度压暗或轻微弱化 
-  NPC与主角半身立绘出现在画面左右 
-  底部出现正式对白框 
-  当前说话角色更突出 
-  非当前说话角色适度降低亮度 
原则：
不切换到完全独立的空白对话页面。
玩家应始终知道自己仍然处于当前场景中。
第一套正式剧情对话样板确定为：
“第一桶金”任务中的白石商行伙计。
样板内容至少验证：
-  当前白石街背景 
-  背景压暗 
-  NPC半身像 
-  主角半身像 
-  底部对白框 
-  当前角色姓名 
-  点击继续 
-  当前说话人物视觉强调 
-  PC显示 
-  微信横屏显示 
-  不遮挡关键安全区域 
不在这一阶段增加复杂镜头运动、Live2D、大量动画或复杂表情切换。
正式样板方向确认：
- 白石商行定位为“江南小镇带现代建筑风格的文雅商行”，比普通杂货铺更规整、体面，并具有明确商号感。
- 白石商行伙计确定为年轻男伙计，气质清爽、机灵、可靠、亲切，承担新手阶段关键引导职责。
- 主角应尽快升级为正式 Q 版人物，当前程序原型小人仅作为过渡，不作为长期视觉方案。
- 正式样板优先顺序为：白石商行建筑、白石商行伙计 Q 版人物、白石商行伙计半身对话立绘、主角正式 Q 版基础样板。
- 当前先建立并验证正式美术样板标准，不要求一次性完成整条白石街的正式美术。
- 样板通过后，再按同一规范扩展至横阳客栈、陈掌柜、街坊杂货铺及其店员。
第一套正式美术样板采用：
建筑：白石商行
人物：白石商行伙计
先完成并接入游戏确认：
-  建筑风格 
-  建筑比例 
-  门洞 
-  建筑锚点 
-  屋檐前景 
-  NPC比例 
-  NPC脚底锚点 
-  NPC行走形象 
-  NPC半身立绘 
-  剧情对白画面 
确认样板通过后，再批量推广到其他建筑和人物。
样板确认后，建议依次：
1.  横阳客栈 
2.  陈掌柜 
3.  街坊杂货铺 
4.  街坊杂货铺店员 
5.  青丝美发室 
6.  春衫衣坊 
7.  白石街其他普通NPC 
8.  树冠和屋檐等细部前景 
具体优先级可根据任务需要调整。
正式美术设计和程序接入分开进行，但必须使用同一套规范。
-  建筑视觉设计 
-  角色视觉设计 
-  正式 PNG 
-  前景切片 
-  半身立绘 
-  素材命名 
-  锚点和用途说明 
-  资源放入项目 
-  scale 
-  anchor 
-  depth 
-  scene配置 
-  入口位置 
-  碰撞 
-  NPC落点 
-  前景遮挡 
-  Web / 微信共用 
-  测试 
-  真机校准 
Work 不应在缺少素材信息的情况下自行猜测正式美术坐标。
Web / PC 与微信小游戏端应共用：
-  地图 
-  建筑 
-  人物 
-  NPC 
-  任务UI 
-  商店UI 
-  对话UI 
-  正式视觉资源 
允许不同的主要内容：
-  操作方式 
-  虚拟摇杆 
-  鼠标 / 键盘 
-  安全区 
-  少量布局响应式调整 
-  平台API 
不维护两套不同美术版本。
正式接入素材优先采用：
-  PNG 
-  透明背景 
-  干净边缘 
不建议把需要透明的正式建筑、角色和前景使用 JPG。
文件命名应稳定、统一、可读。
示例：
building_baishi_shop_base.png
building_baishi_shop_fg.png
npc_baishi_clerk_idle.png
npc_baishi_clerk_walk.png
portrait_baishi_clerk_normal.png
tree_baishi_01_base.png
tree_baishi_01_fg.png
实际命名应结合项目现有目录规范，不要求为了符合本示例而进行无必要重命名。
本规范不意味着立即开发以下完整系统：
-  全NPC大量半身立绘 
-  全NPC多表情系统 
-  Live2D 
-  高复杂度剧情演出 
-  完整捏脸系统 
-  数十种发型 
-  发饰系统 
-  复杂好感UI 
-  NPC动态换发型 
-  全套服装商城 
-  大规模人物动画重制 
白石街当前目标仍然是：
做出一套真正可玩的高质量样板，再扩展。
正式建筑至少满足：
-  风格统一 
-  比例合理 
-  门洞明确 
-  落地自然 
-  边缘干净 
-  方便对齐地图 
-  前景拆分合理 
正式人物至少满足：
-  风格一致 
-  头身比统一 
-  脚底锚点清晰 
-  与建筑比例自然 
-  手机上仍有辨识度 
-  NPC之间容易区分 
至少满足：
-  与游戏内角色是同一个人物 
-  发型 / 服装 / 年龄感一致 
-  不出现“场景小人和立绘完全不像”的情况 
-  手机横屏观看清晰 
后续白石街正式美术与对话开发遵循以下顺序：
统一标准 → 白石商行样板 → 游戏接入 → PC测试 → 微信真机测试 → 校准 → 批量复制。
不得反过来先批量生成全部素材，再发现整体风格或比例不合适后重新返工。
