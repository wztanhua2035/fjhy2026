# 第一阶段交付与验证记录

依据：参考资料中的 V2.2，特别是第 35 章第一原型与第 38 章第一开发周期范围。记录日期：2026-09-05。

## 已完成并验证

项目源代码已建立，保留原始两份 Word。服务端、React 后台、共享类型、规则与客户端控制器通过 TypeScript 检查。后台已成功生成生产构建，依赖锁文件已生成；安装后修复了鉴权和静态资源依赖的已知漏洞，最近一次安装审计结果为 0 项。

自动化测试当前 13 项：12 项通过、0 项失败、1 项 PostgreSQL 集成测试跳过。通过项包含完整 HTTP 登录/建角/出旅馆/买米/卖米闭环、初始赠款幂等、20 个并发重试只扣一次、请求号冲突、价格与数量伪造拒绝、交易失败回滚、外观所有权与性别校验、Ghost 外观同步、北京时间营业边界、配置回滚、生产禁用开发登录和弱网重试。

浏览器实际操作已验证：测试账号登录、选择第四个女性基础模板、确认建角后 120 文、进入客栈、通过出口进入白石街。页面截图已人工检查，角色、跟随视角、客栈、邻店、街道 NPC、操作按钮和行囊均正常显示。买卖的完整链路由 HTTP 测试验证，未把它表述为已完成微信真机测试。

## 已准备但尚未完成实环境验收

- Prisma PostgreSQL 模型、迁移 SQL、约束、初始数据、跨连接幂等实现已写好。真实数据库测试尚未运行。曾准备工作区内独立 PostgreSQL 二进制，但启动测试实例被自动审批系统拒绝，返回原因是用量额度不足；没有绕过拒绝启动数据库。后续可运行 `tools/test-postgres-local.mjs`，或使用 CI 的 PostgreSQL 17 环境验收。
- Worker / Redis 任务代码已完成类型检查，未启动 Redis / BullMQ 实例验证调度。Docker 未在本机安装，三个 Dockerfile 未实际构建运行。
- Cocos 项目、入口场景、触摸/键盘操作、TiledMap 加载、共享 Appearance Renderer、微信网络适配已写好。当前机器未检测到 Creator，未执行引擎构建或微信真机测试；`npm run build` 不覆盖 Cocos 引擎脚本。
- Zeabur 服务、数据库、域名、微信 AppID/Secret、CDN、日志告警和备份未在真实账号中创建或配置。没有发布到外网，也没有上传小游戏审核包。

## 明确留给后续阶段

第一阶段并不包括完整 V2.2 商业游戏。下一步优先处理 Cocos 编译与真机问题、PostgreSQL 和容器验收，然后按第 36 章加入真实赠礼/邮箱/羁绊、住宅/商铺产权、离线经营、任务与财富榜。

当前额外提供的是服装购买与换装服务端原型、浏览器入口和公开 Ghost 外观预览；Cocos 完整换装商店 UI、住宅衣柜、加权 Ghost 抽样、NPC 路线动画、远程 Bundle 缓存和差分更新、全部街区和外围可探索地图、正式美术音效、性能与压力测试均未完成。

道路完整拓扑已在服务端配置中保留，首个可游玩场景只覆盖白石街一段。不可把保留的道路 ID 当作已绘制并可进入的完整横阳地图。
