# 微信小游戏真机验收清单（白石街最小体验版）

## 旧坐标卡住时

新版本在登录和读取场景时会由服务端检查旧存档脚点，并把非法位置持久化迁移到当前场景最近合法点。服务端运行日志可搜索 `PLAYER_POSITION_RESTORED`，其中 `before` 是真实旧坐标和碰撞索引/矩形，`after` 是实际恢复坐标。该日志是核对真机账号根因的依据；本地模拟测试坐标不能当作用户存档事实。微信与 Web 都使用服务端返回的位置。

仅本地 DEV 服务端可调用手动安全复位。微信开发版如需按钮，构建前设置 `WECHAT_GAME_DEBUG_SAFE_RESET=true`，`envVersion=develop` 时显示“恢复到安全点”；服务端需 `APP_ENV=DEV` 且非 production。STAGING 和 production 不开放该 API，不需通过复位按钮解决普通玩家的旧存档问题。

## 导入前

1. 在项目根目录运行 `npm.cmd run build:wechat-game`。
2. 在微信开发者工具选择“导入”→“小游戏”，目录选择 `D:\ChatGPTProjects\fjhy\dist\wechat-game`。
3. 选择《富甲横阳》的真实 AppID；不要填写 AppSecret。
4. 在微信公众平台的小游戏设置中，将 request 合法域名加入 `https://api-fjhy-staging.wzpy.net`（只填域名，不要重复写 `https://`，不填路径）。
5. STAGING 使用 wx.login 和云存档；删除本地缓存不会更换微信身份或重置云存档。临时测试账号仅适用于明确打开开发登录并连接 DEV API 的构建。
6. 连接 STAGING 时直接运行 `npm run build:wechat-game`，通过 `wx.login` 登录；STAGING 会按部署规范拒绝 `/v1/auth/dev`。`WECHAT_GAME_DEV_LOGIN=true` 和 `WECHAT_GAME_DEBUG_OPEN_ALL=true` 只用于连接本地 DEV API，不能用于 STAGING/production。若只需显示本地碰撞框，可设置 `WECHAT_GAME_DEBUG_COLLISION=true`。

## 开发者工具检查

- [ ] 启动后保持横屏，画布没有浏览器地址栏或网页滚动区。
- [ ] 预览上传不再提示源码包超过 4 MiB，启动时三个白石街资源分包均能成功加载。
- [ ] 启动页可看到角色预览并能点击“开始”。
- [ ] 白石街正式底图和横阳客栈、街坊杂货铺、白石商行、青丝美发室、春衫衣坊五栋正式建筑正常出现；春衫衣坊前景层能按人物脚底前后关系遮挡。
- [ ] 男女主角正式 spritesheet、五名核心店铺 NPC spritesheet 和名字正常出现；四方向移动、idle 与脚底锚点没有明显漂移；右上角 FPS 有数值。
- [ ] 左下虚拟摇杆持续移动，无选中文字或弹出浏览器复制菜单。
- [ ] 右下互动按钮可进入白石商行、街坊杂货铺，也可从室内返回街道。
- [ ] 接近核心 NPC 可对话；对话时场景压暗、左右 portrait 槽位完整且透明背景正常，关闭对话后场景恢复。
- [ ] 首次与核心 NPC 对话显示“初次结识”，再次对话只显示“已认识”。
- [ ] 接取“第一桶金”后能看见当前目标。
- [ ] 杂货铺购买鸣山大米后，能看见获得物品、花费、铜钱与新目标。
- [ ] 回白石商行出售后，能看见出售、获得铜钱、任务完成与奖励。
- [ ] 《雨前送样》可完成领取布样、交给青丝美发师、返回春衫掌柜汇报并在 REPORT 后领取奖励；中途重登后 tracker 恢复正确步骤。
- [ ] 春衫衣坊南门、其他四栋入口、客栈与白石街出口均能进入和返回正确位置。

## 真机重点检查

- [ ] 使用“预览”二维码在手机微信中打开，自动保持横屏。
- [ ] 刘海、挖孔、圆角区域不遮住左上状态、右上 FPS、左下摇杆或右下按钮。
- [ ] 主角移动、镜头跟随、建筑和 NPC 碰撞没有明显穿模、卡顿或空气墙。
- [ ] 进入/退出室内后位置正确，任务状态和铜钱正确保留。
- [ ] 以 Wi-Fi 与蜂窝网络各试一次，资源加载和操作不会出现明显白屏或长时间卡住。
- [ ] 如已有音频，再确认前后台切换后音频没有异常；当前版本没有新增音频内容。
