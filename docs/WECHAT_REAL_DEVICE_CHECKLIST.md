# 微信小游戏真机验收清单（白石街最小体验版）

## 导入前

1. 在项目根目录运行 `npm.cmd run build:wechat-game`。
2. 在微信开发者工具选择“导入”→“小游戏”，目录选择 `D:\ChatGPTProjects\fjhy\dist\wechat-game`。
3. 选择《富甲横阳》的真实 AppID；不要填写 AppSecret。
4. 在微信公众平台的小游戏设置中，将 request 合法域名加入 `https://api-fjhy-staging.wzpy.net`（只填域名，不要重复写 `https://`，不填路径）。
5. 本次是测试服验收：首次安装会生成一个仅用于测试的临时账号；删除小游戏本地数据后可获得新的测试账号并从创建角色开始。

## 开发者工具检查

- [ ] 启动后保持横屏，画布没有浏览器地址栏或网页滚动区。
- [ ] 启动页可看到角色预览并能点击“开始”。
- [ ] 白石街底图、主角、NPC 正常出现；右上角 FPS 有数值。
- [ ] 左下虚拟摇杆持续移动，无选中文字或弹出浏览器复制菜单。
- [ ] 右下互动按钮可进入白石商行、街坊杂货铺，也可从室内返回街道。
- [ ] 接近 NPC 可对话；接取“第一桶金”后能看见当前目标。
- [ ] 杂货铺购买鸣山大米后，能看见获得物品、花费、铜钱与新目标。
- [ ] 回白石商行出售后，能看见出售、获得铜钱、任务完成与奖励。

## 真机重点检查

- [ ] 使用“预览”二维码在手机微信中打开，自动保持横屏。
- [ ] 刘海、挖孔、圆角区域不遮住左上状态、右上 FPS、左下摇杆或右下按钮。
- [ ] 主角移动、镜头跟随、建筑和 NPC 碰撞没有明显穿模、卡顿或空气墙。
- [ ] 进入/退出室内后位置正确，任务状态和铜钱正确保留。
- [ ] 以 Wi-Fi 与蜂窝网络各试一次，资源加载和操作不会出现明显白屏或长时间卡住。
- [ ] 如已有音频，再确认前后台切换后音频没有异常；当前版本没有新增音频内容。
